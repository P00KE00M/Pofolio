# P0KEM0N — Futuristic Digital Portfolio

A dark, neon-green cinematic portfolio with an animated intro, scroll-driven highway, and interactive vehicle showcases.

## File Structure
- `index.html` — main HTML markup
- `css/style.css` — all styles
- `js/app.js` — all interactions, canvas environment, audio engine
- `assets/` — static assets

## Deploy
Push to `main` and enable GitHub Pages (Settings → Pages → Branch: main, folder: /root).

## Local dev
Any static server works, e.g. `python3 -m http.server`.
